# /balance

查一次 DeepSeek 账户余额，把数字直接说出来。

## 用法

- `/balance` —— 查可用余额（含赠送 / 充值）

## 怎么做

1. 调 `deepseek_balance` 工具（无参数）。
2. 原样转述金额，**不要换算、不要四舍五入**。
3. 工具报"没有找到 API key"时，把它的原话转给用户：它已经说清了查过哪些地方、
   以及要把 `DEEPSEEK_API_KEY` 放到哪。不要说成"接口挂了"。

## 别做的事

- 不要用这个命令回答"这次对话花了多少"——余额接口只给余额，没有消耗明细；
  要算只能前后各查一次再相减，并且要说明那是差值。
- 不要因为余额是个数字就顺手加解读（"看来你用得挺快"）；用户问什么答什么。
